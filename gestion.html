1 Les types d'éléments

Bitwarden ne stocke pas seulement des identifiants et des mots de passe. Vous pouvez enregistrer cinq types d'éléments dans votre coffre :

🔑

Identifiant (Login)

Couples nom d'utilisateur / mot de passe, pour le remplissage automatique dans le navigateur et sur mobile. Peut aussi contenir des clés d'accès (passkeys) et des codes de vérification.

💳

Carte (Card)

Informations de carte bancaire, pour le remplissage automatique lors de vos paiements en ligne.

🪪

Identité (Identity)

Informations personnelles (adresse postale, etc.), pour remplir automatiquement les formulaires en ligne.

📝

Note sécurisée

Texte libre pour toute information que vous souhaitez protéger.

🖥️

Clé SSH

Utilisez Bitwarden comme agent SSH pour vos connexions techniques.

4 Archiver un élément

L'archivage est utile pour désencombrer votre coffre. Les éléments archivés sont exclus des résultats de recherche et des suggestions de remplissage automatique, mais restent inclus dans les exports.

À savoir sur l'archivage
  • Fonctionnalité réservée aux abonnements payants (Premium, organisations payantes). Si l'abonnement expire, vous ne perdez pas l'accès aux éléments archivés.
  • L'archivage est propre à chaque utilisateur : archiver un élément partagé ne l'archive pas pour les autres personnes qui y ont accès.
  • L'archivage ne retire pas les éléments des rapports ni des exports.
  1. Sélectionnez le ou les éléments à archiver et cliquez sur Archiver (Archive) dans la barre d'actions.
  2. Confirmez en cliquant sur Archiver dans la fenêtre.

Désarchiver

Sélectionnez Archive dans les filtres du coffre, cochez le ou les éléments à restaurer, puis choisissez Désarchiver (Unarchive) dans la barre d'actions.

  2. Confirmez en cliquant sur Archiver dans la fenêtre.

Pour archiver un élément :

Pour afficher les éléments archivés :

5 Supprimer un élément

Choisissez votre plateforme pour voir comment supprimer un élément.

Ouvrez le menu d'options (⋮) de l'élément et choisissez Supprimer (Delete). Vous pouvez aussi supprimer plusieurs éléments à la fois via la barre d'actions.

Cliquez sur l'élément pour l'ouvrir, puis sur l'icône Supprimer (corbeille).

Touchez l'élément pour l'ouvrir, puis ouvrez le menu d'options (⋮) et choisissez Supprimer.

Cliquez sur l'élément pour l'ouvrir, puis sur l'icône Supprimer. Vous pouvez aussi supprimer plusieurs éléments à la fois via la barre d'actions.

Utilisez la commande delete pour supprimer un élément.

bw delete item <item-id>

La corbeille du coffre

Les éléments supprimés sont envoyés dans la corbeille, où ils restent 30 jours. Passé ce délai, ils sont définitivement supprimés et non récupérables. Dans la corbeille, vous pouvez Restaurer un élément ou le Supprimer définitivement avant les 30 jours.

Attention Une suppression définitive (ou après 30 jours dans la corbeille) est irréversible : l'élément ne peut plus être récupéré.

Où trouver la corbeille :

  • Application web : sélectionnez Corbeille (Trash) dans le menu Filtres.
  • Extension navigateur : Paramètres → Coffre → Corbeille.
  • Mobile : onglet Coffres, faites défiler jusqu'à Corbeille.
  • Application bureau : sélectionnez Corbeille dans le menu de navigation.

6 Dupliquer (cloner) un élément

Vous pouvez dupliquer n'importe quel élément dont vous êtes propriétaire, pour en créer une copie. Un élément appartenant à une organisation ne peut être cloné que par les membres ayant l'accès « Peut gérer » sur la collection, et uniquement depuis l'application web.

Ouvrez le menu d'options (⋮) de l'élément à dupliquer et choisissez Cloner (Clone).

Ouvrez le menu d'options (⋮) de l'élément à dupliquer et choisissez Cloner (Clone).

Touchez l'élément pour l'ouvrir, puis ouvrez le menu d'options (⋮) et choisissez Cloner.

Ouvrez le menu d'options (⋮) de l'élément à dupliquer et choisissez Cloner (Clone).

Remarque Les clés d'accès (passkeys) ne sont pas copiées lors du clonage. Le nouvel élément reprend tous les détails de l'original, sauf le champ de la clé d'accès qui reste vide.

7 Partager un élément

Si vous êtes membre d'une organisation, vous pouvez assigner des éléments de votre coffre aux collections de l'organisation. Cela transfère la propriété de l'élément à l'organisation.

Pour partager avec d'autres membres de l'organisation, sélectionnez le ou les éléments, puis utilisez l'option Assigner aux collections (Assign to collections) dans la barre d'actions.
